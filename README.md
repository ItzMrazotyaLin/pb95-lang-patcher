# Progressbar95 RU Patcher

Скрипт добавляет отсутствующие строки в русской локализации Progressbar95, используя машинный перевод через библиотеку translators, с поддержкой ручных правок и исключений.

## Возможности

- Автопоиск недостающих ключей (есть в en.xml, нет в ru.xml)
- Машинный перевод без API-ключей через сервисы: bing, alibaba, yandex, google
- Файл исключений skip.txt — ключи, которые не переводятся
- Файл ручных правок translate.txt — готовые переводы вместо машинного
- Защита плейсхолдеров (%s, %d, {0}, \n, \t, [TAG], <...>) при переводе
- Сохранение ведущих и замыкающих пробелов, переносов строк
- Запись результата в отдельный ru_patched.xml (оригиналы не трогаются)
- UTF-8 без BOM с сохранением декларации `encoding='utf-16'`

## Требования

- Python 3.8+
- translators

## Установка

```bash
pip install -r requirements.txt
```

## Использование

1. Положите рядом со скриптом файлы `en.xml` и `ru.xml` из файлов игры (C:\Program Files (x86)\Steam\steamapps\common\Progressbar95\Resources\international\en и \ru).
2. (Опционально) Создайте `skip.txt` и `translate.txt`, если нужны исключения или ручные правки.
3. Запустите:
   ```bash
   python patch_ru.py
   ```
4. Заберите готовый `ru_patched.xml` и положите его в игру вместо оригинального `ru\strings.xml` (не забудьте сделать бэкап оригинала).

Оригинальные `en.xml` и `ru.xml` не перезаписываются.

## Файл skip.txt

Классы, которые не надо переводить. Формат: одно имя класса на строку, `#` — комментарий. Пустые строки игнорируются.

Пример:
```
# Названия режимов не переводим
GameModexs
GameModeys
```

Если ключ из skip.txt уже есть в ru.xml — он остаётся как есть, skip влияет только на новые строки.

## Файл translate.txt

Ручные переводы, минуя машинный. Формат одной строки:
```
ClassName="Готовый перевод";
```

Точка с запятой в конце обязательна. Кавычки могут быть одинарные или двойные. `#` — комментарий. Пустые строки игнорируются.

Пример:
```
# Переводчики ломают PI-BI на ПИ-БИ
PIBIHacker="Хакер PI-BI";
```

Если ключ уже есть в ru.xml — ручной перевод игнорируется с предупреждением. Если ключа нет ни в en.xml, ни в ru.xml — выводится предупреждение.

## Как это работает

1. Чтение `en.xml` и `ru.xml`.
2. Чтение `skip.txt` и `translate.txt` (если есть).
3. Поиск недостающих ключей (есть в en.xml, нет в ru.xml).
4. Исключение ключей из skip.txt.
5. Подстановка ручных переводов из translate.txt, удаление этих ключей из очереди на машинный перевод.
6. Копия `ru.xml` в `ru_patched.xml` без изменений.
7. Машинный перевод оставшихся ключей через translators (перебор сервисов, 3 попытки, пауза 2 сек).
8. Запись машинных и ручных переводов в `ru_patched.xml` перед закрывающим тегом корня.

## Ограничения

- Качество машинного перевода неидеально — ключевые строки лучше править через translate.txt.
- Скрипт не проверяет, что ru_patched.xml совместим с конкретной версией игры — тестируй в игре.
- Не работает, если формат XML в игре изменится (нестандартные теги, CDATA внутри `<t>` и т.п.).
- Не залезает в файлы игры и ничего там не меняет.
